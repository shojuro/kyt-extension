# KYT Memory Extension - Privacy Policy

**Last Updated: February 11, 2026**

## Overview

KYT Memory ("the Extension") is a Chrome extension that provides cross-platform memory for AI conversations. It captures messages from ChatGPT and Claude, stores them securely, and retrieves relevant past context to enhance future conversations.

This policy explains what data we collect, how we use it, and your rights regarding that data.

## Data We Collect

### Conversation Content
- **What**: Text content of messages you send and receive on ChatGPT (chatgpt.com, chat.openai.com) and Claude (claude.ai).
- **Why**: To build a searchable memory of your AI conversations so relevant past context can be retrieved and injected into future conversations.
- **How**: Content scripts intercept outgoing API requests on supported platforms to capture message text.

### Conversation Metadata
- **What**: Timestamps, platform source (ChatGPT/Claude), conversation IDs, speaker roles (user/assistant).
- **Why**: To organize conversations chronologically and by platform for accurate retrieval.

### Semantic Embeddings
- **What**: Mathematical vector representations (4096 dimensions) of your conversation content, generated by AI models.
- **Why**: To enable semantic search — finding past conversations by meaning, not just keywords.

### Usage Statistics
- **What**: Aggregate counts of messages captured, search queries performed, and injection success/failure rates.
- **Why**: To monitor extension health and improve search quality.

## Data We Do NOT Collect

- Passwords or login credentials
- Financial information
- Browsing history outside of ChatGPT and Claude
- Personal files or documents
- Data from any website other than chatgpt.com, chat.openai.com, and claude.ai

## How Data Is Stored

### Server-Side Storage
Conversation content, embeddings, and metadata are stored in a **Supabase** (PostgreSQL) database with the following security measures:
- Row Level Security (RLS) policies ensure each user can only access their own data.
- All data is transmitted over HTTPS/TLS encryption in transit.
- Database is hosted on Supabase's managed infrastructure with encryption at rest.

### Local Storage
The extension uses `chrome.storage.local` to temporarily store:
- Recently captured messages (before sync to server)
- API configuration and authentication tokens
- Extension settings and preferences
- Circuit breaker state for API reliability

## Third-Party Services

The Extension uses the following third-party services to process your data:

| Service | Purpose | Data Sent |
|---------|---------|-----------|
| **Supabase** | Database storage and authentication | Conversation content, embeddings, metadata |
| **HuggingFace (Scaleway)** | Generate semantic embeddings (Qwen3-Embedding-8B model) | Conversation text (for embedding generation) |
| **OpenAI** | Generate hypothetical search queries (gpt-4o-mini) | Conversation text (for HyDE generation) |
| **Jina AI** | Cross-encoder reranking of search results | Search queries and candidate result text |

Each third-party service has its own privacy policy:
- [Supabase Privacy Policy](https://supabase.com/privacy)
- [HuggingFace Privacy Policy](https://huggingface.co/privacy)
- [OpenAI Privacy Policy](https://openai.com/privacy)
- [Jina AI Privacy Policy](https://jina.ai/legal)

## Chrome Extension Permissions

| Permission | Reason |
|-----------|--------|
| `storage` | Store captured messages locally, extension settings, and authentication tokens |
| `alarms` | Schedule periodic sync operations, health checks, and embedding model warm-up |
| `scripting` | Inject content scripts into ChatGPT and Claude pages to capture and enhance conversations |
| Host permissions for `chatgpt.com`, `chat.openai.com`, `claude.ai` | Required to run content scripts that capture messages and inject memory context on these specific sites |

## Data Retention

- Conversation data is retained indefinitely until you request deletion.
- Local storage data is subject to Chrome's storage limits and LRU eviction when approaching quota.
- Cost tracking and usage statistics are retained for billing and diagnostics.

## Your Rights

### Access Your Data
You can view all captured conversations through the extension's popup interface.

### Delete Your Data
- **Local data**: Clear via Chrome's extension storage management or by uninstalling the extension.
- **Server data**: Contact us to request complete deletion of your server-side data. We will delete all associated records within 30 days.

### Export Your Data
Contact us to request an export of your stored conversation data.

### Opt Out
You can disable the extension at any time through Chrome's extension management page. Disabling stops all data capture immediately. Previously stored data remains until you request deletion.

## Data Security

- All API communications use HTTPS/TLS encryption.
- API keys are stored in `chrome.storage.local` (not in source code or cookies).
- Database access is protected by Row Level Security — users cannot access other users' data.
- Circuit breakers prevent cascading failures and protect against data loss during API outages.

## Children's Privacy

This extension is not directed at children under 13. We do not knowingly collect personal information from children.
