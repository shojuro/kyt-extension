Quick Start

  1. Install the Chrome extension from the Chrome Web Store (or load unpacked for development).
  2. Open any supported platform — ChatGPT, Claude, or Gemini.
  3. Start talking. K.Y.T. captures your conversations silently in the background.
  4. Switch platforms. Open a different AI. K.Y.T. automatically injects relevant context from your other conversations.

No API keys. No configuration. No setup wizards. Just install and talk.

Claude Code (MCP)

For Claude Code users, K.Y.T. provides an MCP server that bridges your terminal sessions to your conversation memory. Add it to your .mcp.json and your CLI sessions are captured alongside your browser conversations.

Privacy Modes

K.Y.T. supports three privacy modes. Switch between them at any time from the extension popup.

  • Full — Everything is captured and injected. This is the default. Your AI remembers everything.
  • Clean Room — Conversations are captured, but nothing is injected into your prompts. Useful when you want to record a conversation without external context influencing the response.
  • Incognito — Nothing is captured or injected. The session is completely off the record.

Privacy mode is a client-side setting. It controls what the extension sends, not what the server stores. In Incognito mode, no data leaves your browser.

Platform Notes

ChatGPT

Full capture + injection. Works with all ChatGPT conversation types. Context is injected as a system-level prefix before your message is sent.

Claude (Web)

Full capture + injection. Works with claude.ai conversations. Same injection mechanism as ChatGPT.

Gemini

Capture + injection via XHR interception. Gemini uses XHR (not fetch) for message delivery, so K.Y.T. intercepts at the XHR level.

Claude Code (MCP)

Memory query, entity search, and note saving via MCP tools. Session ingestion captures your terminal conversations to Supabase. Automatic context injection via the UserPromptSubmit hook.

Search & Recall

K.Y.T. provides two ways to recall past conversations:

  • Automatic injection — When you type a message on any supported platform, K.Y.T. searches your memory for relevant context and injects it before your message is sent. You don't need to do anything.
  • Manual search — Open the extension popup and type a query. K.Y.T. returns matching conversations ranked by semantic similarity, with source platform and date.

Search uses a hybrid approach: vector embeddings (1024d Qwen3 Matryoshka) for semantic meaning + BM25 for keyword matching. Results are fused via Reciprocal Rank Fusion.

Data Management

Export

Export all your conversations as JSON from the extension settings. The export includes messages, embeddings metadata, and entity data.

Delete

Delete all your data with one click from the extension settings. This removes all messages, embeddings, entities, and preferences from Supabase. This action is irreversible.

Where is my data stored?

Your data is stored in a Supabase PostgreSQL database with Row Level Security (RLS). Only your authenticated user ID can access your data. Embeddings are indexed with HNSW for fast vector search.

Troubleshooting

K.Y.T. isn't capturing my conversations

  • Check that the extension is enabled (icon should be visible in your toolbar).
  • Check your privacy mode — if it's set to Incognito, nothing will be captured.
  • Refresh the page. The extension needs to inject its content scripts on page load.
  • Check the browser console for errors (right-click → Inspect → Console).

Context isn't being injected

  • Check your privacy mode — Clean Room mode disables injection.
  • Check that you have saved conversations. K.Y.T. needs data to inject.
  • The injection pipeline takes 12–16 seconds on the first query (cold start). Subsequent queries are faster.

Search returns no results

  • Check that your conversations have been synced (look for the sync indicator in the popup).
  • If you recently imported conversations, the embedding backfill may still be running. Wait a few minutes.
  • Try a broader query. Semantic search works best with natural language, not exact phrases.
